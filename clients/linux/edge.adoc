edge(1)
=======

== Name
edge - Vault VPN linux client

== Synopsis
*edge* --config <FILE> [OPTIONS]

*edge* -s quit

== Description
edge is a Linux VPN client compatible with the Vault VPN protocol.
It connects to a supernode server over an encrypted UDP tunnel (SPAKE2 password
authentication, X25519 ECDH key exchange, HKDF-SHA256 and AEAD encryption), takes over the system default route via a TUN
device and keeps the connection alive with periodic heartbeats and automatic
reconnect with exponential backoff.

== Options
*--config* <FILE>::
    Read configuration options from the specified TOML file.

*--log-dir* <DIR>::
    Write logs to this directory (default: /var/log/vault/). Logs are written
    only to files, including in foreground mode. Current log files have no date suffix (for example, default.log). On the
    first write after a UTC date change, the old file is archived with its
    last-write date (default.log.YYYY-MM-DD). Each stream keeps at most 30
    files, including the
    current file; older files are removed when that stream is initialized or
    rotates. This is a file-count limit, not a size or age limit.

*--daemon*::
    Run the process in the background.

*--pid-file* <FILE>::
    Store the process id in this file when daemonizing.

*--user* <USER>::
    After reading the configuration and acquiring the control socket, switch to this user before starting background threads. Requires starting as root. The log directory and storage parent must support file creation, append, rename and deletion.

*--group* <GROUP>::
    Run as other group. Requires starting as root when changing identity.

The process retains CAP_NET_ADMIN, CAP_NET_RAW and CAP_DAC_OVERRIDE for network setup and access to configuration and control files. This option changes identity but is not a complete privilege sandbox. Debian systemd services instead start directly as the dedicated *vault* user and group with these capabilities supplied by systemd. The systemd-resolved backend also requires Polkit authorization; the Debian package installs the corresponding account-scoped rule.

*-s* <S>::
    Send a control signal to a running instance. Only *quit* is supported.

*-v, --verbose*::
    Print debug information.

*-q, --quiet*::
    Only print errors and warnings.

*--version*::
    Print the version and exit.

*-h, --help*::
    Print help information.

SIGINT and SIGTERM use the same graceful shutdown and network cleanup path as *-s quit*.

== DNS
Automatic DNS requires systemd-resolved's local stub: */etc/resolv.conf*
nameservers must all be *127.0.0.53* or *127.0.0.54*, and *resolvectl statistics*
must succeed. With Polkit authorization, Edge configures DNS on its own TUN
and reverts the link settings on exit. Other setups, including
*/run/systemd/resolve/resolv.conf* uplink mode, require manual DNS configuration.
Edge leaves */etc/resolv.conf* unchanged.

== Route recovery
Reserve route protocol *242* for Edge within its network namespace. On restart,
Edge recovers marked routes for the current server addresses.
For conflicts with legacy *proto static* routes, inspect the route in the log
and confirm ownership before removing it manually.

== Files
*/etc/vault/edge.toml*::
    Configuration file. See *edge.toml.example* for the available options
    (password, host, port, iface, dns_ipv4, dns_ipv6, storage).

*/run/edge.socket*::
    Unix datagram socket used to deliver the quit signal to a running
    instance.

*/run/edge.socket.lock*::
    Persistent file used for the process-lifetime instance lock. Duplicate
    starts cannot replace an active control socket. Do not delete the lock
    file while the service is running.
