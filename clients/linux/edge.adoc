edge(1)
=======

== Name
edge - Vault VPN linux client

== Synopsis
*edge* --config <FILE> [OPTIONS]

*edge* -s quit

== Description
edge is a Linux VPN client compatible with Vault protocol v2. Use a v2 Supernode.
It connects to a supernode server over an encrypted UDP tunnel (SPAKE2 password
authentication, X25519 ECDH key exchange, HKDF-SHA256 and AEAD encryption), takes over the system default route via a TUN
device and keeps the connection alive with periodic heartbeats and automatic
reconnect with exponential backoff.

== Peer-to-peer traffic
Eligible VPN peers use encrypted direct UDP after verifying a path. Traffic
uses the Supernode while probing and when a direct path fails. Internet traffic
uses the Supernode.

Edge automatically uses eligible public and LAN candidates. Supernode
forwarding policy and relay counters apply to traffic handled by the server.

IPv4 direct routing needs an effective physical-interface *rp_filter* of
0 or 2. The effective value is the larger of the host-wide *all* setting and
the physical-interface setting. Edge uses relay if the value is 1 or unavailable.

== Options
*--config* <FILE>::
    Read configuration options from the specified TOML file.

*--profile* <NAME>::
    Select a named profile from the configuration file. Overrides *default_profile*.

*--log-dir* <DIR>::
    Write logs to this directory (default: /var/log/vault/). Logs are written
    only to files, including in foreground mode. Current log files have no date suffix (for example, default.log). On the
    first write after a UTC date change, the old file is archived with its
    last-write date (default.log.YYYY-MM-DD). Each stream keeps at most 30
    files, including the
    current file; older files are removed when that stream is initialized or
    rotates. This is a file-count limit, not a size or age limit.

*--daemon*::
    Run the process in the background.

*--pid-file* <FILE>::
    Store the process id in this file when daemonizing.

*--user* <USER>::
    After reading the configuration and acquiring the control socket, switch to this user before starting background threads. Requires starting as root. The log directory and storage parent must support file creation, append, rename and deletion.

*--group* <GROUP>::
    Run as other group. Requires starting as root when changing identity.

The process retains CAP_NET_ADMIN, CAP_NET_RAW and CAP_DAC_OVERRIDE for network setup and access to configuration and control files. This option changes identity but is not a complete privilege sandbox. Packaged systemd services instead start directly as the dedicated *vault* user and group with these capabilities supplied by systemd. The DNS backends also require Polkit authorization; Debian and RPM packages install the corresponding account-scoped rule.

*-s* <S>::
    Send a control signal to a running instance. Only *quit* is supported.

*-v, --verbose*::
    Print debug information.

*-q, --quiet*::
    Only print errors and warnings.

*--version*::
    Print the version and exit.

*-h, --help*::
    Print help information.

SIGINT and SIGTERM use the same graceful shutdown and network cleanup path as *-s quit*.

== DNS
With systemd-resolved's local stub and Polkit authorization,
Edge configures DNS and the *~.*
routing domain on its own TUN and reverts the link settings on exit.

Otherwise, Edge checks the nameservers in */etc/resolv.conf* every two seconds,
including when NetworkManager generates the file. It needs write access only
when the nameserver list differs from the selected servers. Edge journals edits
before writing. Normal shutdown or the next startup restores an Edge-owned edit
while preserving replacement files and unrelated changes. With the file backend,
replacement of the resolver file causes Edge to exit and systemd to restart it
with a fresh writable mount. Each resolver command has a two-second timeout.

== Route recovery
Reserve route protocol *242* for Edge within its network namespace. On restart,
Edge recovers marked routes for the current server addresses.
For conflicts with legacy *proto static* routes, inspect the route in the log
and confirm ownership before removing it manually.

== Files
*/etc/vault/edge.toml*::
    Configuration file. Global *iface*, *storage* and *default_profile* options
    are combined with named *[profiles.<name>]* sections containing password,
    host, port and DNS options. The old flat single-profile format is rejected.

*/run/edge.socket*::
    Unix datagram socket used to deliver the quit signal to a running
    instance.

*/run/edge.socket.lock*::
    Persistent file used for the process-lifetime instance lock. Duplicate
    starts cannot replace an active control socket. Do not delete the lock
    file while the service is running.
